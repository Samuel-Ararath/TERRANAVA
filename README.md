Terranava 🌱

Turning Food Waste Into Sustainable Value

Terranava is a green economy and circular waste management platform designed to transform food waste generated by Hotels, Restaurants, and Cafés (HORECA) into valuable resources.

Instead of treating food waste as an endpoint, Terranava connects waste collection, route optimization, organic waste processing, sustainability monitoring, and ESG reporting into one integrated digital ecosystem.

«From food waste to measurable impact.»

🌐 Live Website: https://terranava-prod.vercel.app/
📦 Repository: https://github.com/tester-1102/Terranava

🌍 About Terranava

The HORECA industry generates significant amounts of organic waste every day. Much of this waste is still treated as ordinary waste, resulting in unnecessary disposal, transportation, and environmental impact.

🎯 Project Goals

Terranava is designed to help businesses:

- ♻️ Reduce organic waste sent to landfill
- 🌱 Create value from food waste
- 🪰 Utilize organic waste for maggot / BSF cultivation
- 🌾 Support the production of organic fertilizer
- 🚚 Improve waste collection efficiency through route optimization
- 📊 Monitor waste generation and diversion
- 🌍 Measure environmental impact and carbon reduction
- 📑 Generate sustainability and ESG reports
- 🏢 Provide businesses with a centralized sustainability workspace

✨ Core Features

♻️ Organic Waste Management

Track organic waste generated by participating HORECA businesses and monitor how much waste is successfully diverted from conventional disposal.

The platform provides visibility into:

- Waste collection volume
- Collection activity
- Diversion performance
- Historical waste data
- Operational efficiency

---

🚚 Smart Route Optimization

Terranava integrates route optimization into the waste collection workflow.

The objective is to determine efficient collection routes based on operational requirements, helping reduce:

- Unnecessary travel
- Collection time
- Transportation costs
- Fuel consumption
- Associated carbon emissions

This creates a more efficient connection between HORECA waste sources and processing facilities.

---

🪰 Circular Processing

Collected organic waste can be redirected into productive applications instead of being treated purely as waste.

Potential applications include:

Maggot / BSF Feed

Organic food waste can be utilized as feedstock for Black Soldier Fly cultivation, creating an alternative pathway for transforming food waste into useful biomass.

Organic Fertilizer

Processed organic material can also be directed toward fertilizer production, supporting agricultural applications and nutrient cycling.

The overall concept follows a circular economy model where resources remain in productive use for as long as possible.

---

📊 Impact Dashboard

Terranava provides a centralized dashboard for monitoring sustainability performance.

Example metrics include:

- Organic waste managed
- Waste diversion rate
- Carbon impact
- Collection efficiency
- Daily and monthly waste volume
- Smart bin/device status
- Collection activity

This allows businesses to understand their sustainability performance through measurable indicators.

---

🌱 ESG Reporting

Terranava connects operational waste data with sustainability reporting.

The platform is designed to support the generation of ESG-oriented reports containing information such as:

- Environmental impact
- Organic waste diversion
- Carbon emission reduction
- Waste management performance
- Operational sustainability metrics

This transforms raw operational data into information that can be used for sustainability monitoring and reporting.

---

📡 Smart Bin Monitoring

Terranava supports connected waste collection infrastructure through Smart Bin monitoring.

Businesses can monitor:

- Device status
- Collection points
- Operational health
- Synchronization status
- Collection activity

This provides better visibility across distributed waste collection locations.

🚀 Getting Started

Prerequisites

Make sure you have installed:

- Node.js
- pnpm
- Git

1. Clone the repository

git clone https://github.com/tester-1102/Terranava.git
cd Terranava

2. Install dependencies

pnpm install

3. Run the development server

pnpm dev

Open:

http://localhost:3000

4. Build for production

pnpm build

5. Start the production server

pnpm start
